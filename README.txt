DURAFSHAN SAKEENA SYED — ACADEMIC WEBSITE

This package contains the current full website draft, including research images, selected publications, teaching and mentoring, three embedded YouTube videos, media coverage, contact information, and a CV PDF.

FILES
- index.html: website content
- assets/style.css: layout and visual styling
- assets/images/: selected portrait and four research figures
- cv.pdf: current CV PDF
- IMAGE_GUIDE.txt: figure selection notes

UPLOAD TO GITHUB
1. Download this ZIP and extract it on your computer.
2. Open your repository: https://github.com/SyedDurafshan/SyedDurafshan.github.io
3. Choose Add file > Upload files.
4. Upload the CONTENTS of the extracted folder (index.html, cv.pdf, README.txt, IMAGE_GUIDE.txt, and the assets folder). Do not upload the ZIP itself.
5. Confirm index.html is at the repository root and assets/style.css plus assets/images/ are in the right folders.
6. Commit changes.
7. Review the repository files. When ready to publish, open Settings > Pages, choose Deploy from a branch, select main and /(root), and save.

PUBLICATION NOTE
The repository is public, so uploaded files can be viewed by others even before GitHub Pages is enabled. Review the content and the CV PDF before uploading if you do not want them public yet.
